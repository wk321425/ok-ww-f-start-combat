# F 开始战斗（ok-ww 插件）

在挑战 / 副本里按下键盘上的 F 后，不等锁定目标或血条出现，就直接开始自动战斗，让起手动作尽早放出来。默认等待 0 秒，可以设一个等待时间来对齐刷怪。

**仅建议在矩阵 / 深塔 / 海墟等高难战斗本中使用。** 大世界里按的 F 会被忽略，但平时不用时，还是建议在「触发任务」里把它关掉。

这是第三方插件，不是 ok-ww 官方功能。出了问题请在本仓库提 issue，不要去 ok-ww 主仓库报。

## 安装

1. 需要带插件页的 ok-ww（ok-script 2.0.15 起）。
2. 两种装法任选一种：
   - 在插件页填仓库地址 `wk321425/ok-ww-f-start-combat`，从 Release 安装，以后还能检查更新；
   - 从 [Releases](https://github.com/wk321425/ok-ww-f-start-combat/releases) 下载 `f_start_combat-<版本>.zip`，在插件页选「导入本地文件」。
3. 导入后到「触发任务」里打开「F 开始战斗」。框架在导入插件时会先把所有自定义任务关掉，所以导入后要手动打开一次。
4. 日志里出现 `F 开始战斗 v1.0.0: 补丁已挂上` 就说明装好了。

如果以前用过 `ok_tasks/FStartCombatTask.py`，请先删掉它再导入。两份同时存在时，插件会报错并且不生效。

## 选项

| 选项 | 默认 | 说明 |
|---|---|---|
| F 之后等待(秒) | 0 | 按下 F 到开始战斗之间等待的秒数，用来对齐刷怪 |
| 没锁到目标最多撑(秒) | 10 | 开打后怪还没出来时，这段时间里不判脱战、也不停下来找怪，宏照常出招；超过这个时间，就回到原规则：找 3 秒怪，找不到算脱战。填 0 = 一直撑到锁到目标 |

## 工作方式

- 后台线程每 50ms 读一次物理 F 键，而且只在游戏窗口位于前台时记录按下。ok-ww 自己发出的按键走 PostMessage，读不到，所以拾取、处决这些脚本自己按的 F 不会触发。
- 自动战斗判断「还没进战斗」时，如果刚按过 F、等待时间也到了，就直接判成已进战斗；Auto Target 打开时会顺手点一下中键锁定。
- 每次按下只用一次。超过「等待时间 + 10 秒」还没用上的按键作废。打开自动战斗之前按的 F、战斗过程中和战斗结束前按的 F 都不算。
- 保护期：从开打到第一次锁到目标之间，每次战斗检查只补点一下中键就放行，不会像原规则那样卡 3 秒找怪、找不到就脱战。锁到目标后保护期结束，之后完全按原规则走。

## 已知限制

- 开打时不保证已经锁定目标。主程序里有些角色代码默认「开打 = 已锁定」：
  - 内置的椿每帧都检查有没有锁定，保护期内锁不到目标时，她会反复松开、重按重击；
  - 有些工坊代码只要看到队伍栏就跳过战斗检查，根本不走找怪那一步，所以和保护期无关：副本里拾取、交互按的 F 可能开出一场空战斗，要等队伍栏消失才会停。
- 插件是在运行时给 ok-ww 的几个内部函数打补丁（`CombatCheck.do_check_in_combat / has_target / target_enemy / do_reset_to_false`，`AutoCombatTask.enable / combat_end`）。ok-ww 更新后，如果这些函数改名或删掉了，插件不会安装，日志会报 `ok-ww 改了这些函数`。如果主程序以后自带了同样的功能，插件也会自动停用。
- 卸载插件后补丁会马上卸下，后台读键线程也会停止。

## 开发

- 打包：`python build.py`，输出 `dist/f_start_combat-<版本>.zip` 和 `.okscript`。需要能 import ok-script：放在 ok-ww 源码目录旁边，或者已经用 pip 装好 ok-script。版本号要同时改 `manifest.json` 和 `FStartCombat.py` 里的 `PLUGIN_VERSION`。
- 测试：`python tests/test_f_start_combat.py <ok-ww 源码目录> dist/f_start_combat-<版本>.okscript`。测试会用 ok-script 自己的导入流程装一遍再跑。
